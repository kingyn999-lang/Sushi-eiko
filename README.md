# Sushi Eiko

The website for Sushi Eiko, a Japanese restaurant in Pinhal Novo. It includes the home page, restaurant story, rodízio, menu, ordering information, gallery, and visitor information.

The site uses static HTML, inline CSS and JavaScript, and local image assets. Netlify publishes the `public` directory without a build step.

To view locally, run `python3 -m http.server 8080 --directory public` and open http://localhost:8080.
